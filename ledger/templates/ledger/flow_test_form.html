Computed by POST /api/v1/compute-preview/ — the same route the API serves, so the number you see here is the number that will be stored. Formula {{ formula_version }}.

How the numbers are made

Q_F — the total discharge from the pitot readings, or the meter total when one is given.

Q_R — the rated available flow extrapolated to {{ target_residual_psi|floatformat:0 }} psi residual, capped at {{ max_static_psi|floatformat:0 }} psi static.

Class — the NFPA 291 colour class of that rated flow. Provisional bands; verify against a licensed NFPA 291 edition before relying on them.

Warnings — {{ warnings|length }} checks run on every test (below-target static, sub-target residual, excessive extrapolation, meter/pitot divergence, duplicate readings). A warning is information: it never silently changes a stored number.
