Dispatch CSV

viewer-readable

One row per hydrant in service, in fixed column order, carrying the field-verify literal "{{ verify_in_field }}" and the disclaimer on every row. Retired hydrants are excluded, a leading = is neutralised so a spreadsheet cannot execute a cell, and west longitudes are written un-prefixed.

The file is a download, not a page — a browser will save it rather than render it.

Imports

two-phase, audited

Every import is a dry run followed by a commit: the dry run stores the exact file it read and returns row-level errors; the commit requires a single-use, user-bound token that expires after 24 hours. A re-upload at commit time is hash-checked against the dry run.

Hydrant template Parcel template Flow-test template

Importing is an API operation by design — it is scriptable, and the dry run is what makes it safe. POST /api/v1/imports/hydrants/ with mode=DRY_RUN, then again with the returned commit token. The history is an API read: GET /api/v1/imports/.
